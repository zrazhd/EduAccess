# Contributing to EduAccess

Thanks for your interest in contributing. EduAccess is a small open-source project and we're happy to have help from anyone who wants to improve it.

---

## How to contribute

### Report a bug

Open an issue on GitHub. Please include:
- What you were trying to do
- What happened instead
- Your OS and Programming Languages version

### Suggest a feature

Open an issue with the label `enhancement`. Describe the problem you're trying to solve and why it would be useful for schools.

### Submit code

1. Fork the repository
2. Create a new branch: `git checkout -b feature/your-feature-name`
3. Make your changes
4. Test locally to make sure nothing is broken
5. Commit with a clear message: `git commit -m "Add subject filter to browse page"`
6. Push your branch and open a pull request

---

## Code style

- Keep functions small and focused
- Add a comment if something isn't obvious
- Don't add dependencies without a good reason — this project needs to run on minimal hardware

---

## What we're looking for

Here are some areas where contributions would be especially useful:

- Support for more file types
- Multilingual interface (especially Kazakh and Russian)
- Offline installer for Windows/Linux

---

## What to avoid

- Please don't open pull requests that only fix whitespace or rename variables
- Don't add cloud dependencies — the whole point is offline operation

---

## Code of Conduct

Be respectful. We're building something for schools and communities, and the project should reflect that. If you're unsure about something, just ask.

---

## Questions?

Open an issue or reach out to the team.
